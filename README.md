# pico. web

pico.のGitHub Pages向け公開版です。

- `index.html` はドット絵変換・タッチ修正・PNG書き出しに対応しています。
- 画像変換はブラウザ内で完結し、外部APIを呼びません。
- Privateの開発用リポジトリのコミット履歴はコピーしていません。

## GitHub Pagesの設定
Settings → Pages → Build and deploymentで `Deploy from a branch`、Branchを `main`、Folderを `/(root)` にしてSave。

## 確認事項
iPhone Safari実機での画像選択、変換、ドット修正、PNGダウンロードは未検証です。
